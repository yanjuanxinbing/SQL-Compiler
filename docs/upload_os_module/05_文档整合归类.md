## 2. 按类别合并整理说明

### 2.1 开发计划（合并后主线）

将 `OS_Module_Development_Plan.md`（总体）与 `Storage_Dev_Plan.md`（分阶段）合并阅读，可得到完整时间线：

1. **基础阶段**：页式存储 → 缓冲池 → LRU/FIFO 替换 → 统一接口对接执行计划（指导书必修）；
2. **扩展阶段 E1–E8**：空闲页 `.fpl` 持久化、页 CRC、真持久 fsync、组提交、页级读写闩、后台刷脏、内存上限、块设备故障注入；
3. **事务与隔离深入**：多会话并发、锁管理器（死锁检测）、隔离级别（RC/SERIALIZABLE/SNAPSHOT）、行级锁、谓词锁、MVCC 快照、FCW、二级索引可见性、行锁升级、后台真空；
4. **OS 优化 Phase 1–4**：B+Tree 乐观页级并发（3.18× 吞吐）→ 快照低水位 O(1) + 内联真空（500× 读加速）→ 版本链 O(1) + 索引墓碑回收 → 谓词区间树 + WAL 组提交 + 温度感知刷盘。

### 2.2 设计文档（合并后主题）

- **总体设计**：`Page_Management_Design.md` + `OS_Module_Development_Plan.md` §2；
- **并发机制**：隔离级别三份 + 锁升级 + 谓词合并 + MVCC 快照 + 二级索引可见性 + 后台真空；
- **OS 优化**：Phase 1–4 四份机制文档，每份含实现原理、并发安全性论证、实测数据与验收指标。

### 2.3 测试与验收报告（合并后结论）

| 报告 | 结论 |
|---|---|
| Storage_Subsystem_Acceptance_Report | 基础需求全部满足，E1–E8 扩展验收通过 |

### 2.4 开发日志说明

本项目未单独维护“开发日志”文件；各轮次的开发过程、问题与修复已内嵌在
`Storage_Dev_Plan.md` 的里程碑记录（T2 各子条目含「修复 xxx 竞态/死锁/漏锁」等详细日志）
与各轮次总结/验收报告的“机制实现摘要”中。本轮（2026-09-13）新增的**测试问题日志**
