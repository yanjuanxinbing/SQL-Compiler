## 3. 模块一句话概览

- **页式存储**：固定 4KB 页、唯一页号、`read_page`/`write_page`/分配/释放接口；
- **缓存管理**：缓冲池（pin 计数 + 脏标记 + 命中统计 + 替换日志），LRU / FIFO / CLOCK / LRU-K 可插拔替换；
- **持久化**：WAL-before-data、真持久 fsync、组提交、页 CRC（`.crc`）、空闲页位图（`.fpl`）、崩溃恢复（redo/undo + CLR 链）；
- **并发与事务**：页级读写闩、行锁/表锁/谓词锁、死锁检测、隔离级别（RC/SERIALIZABLE/SNAPSHOT）、MVCC 版本链、FCW、乐观 B+Tree 页级并发；
- **优化**：快照低水位 O(1)、内联真空、谓词区间树、温度感知刷盘、LRU-K、内存上限可配、后台刷脏/真空。
