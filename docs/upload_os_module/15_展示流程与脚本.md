## 2. 分段落编排

### 段 1：模块介绍（3 min）
- 一句话定位：**物理存储底座**——向上层（存储引擎/索引/目录/事务/执行器）提供以「页」为单位的缓冲与磁盘访问接口。
- 四层架构（[04_模块设计文档.md](04_模块设计文档.md) §1.2）：物理介质 → DiskManager+BlockDevice → 替换策略族 → BufferPoolManager → 上层消费者。
- 交互关系：编译模块（词法/语法/语义/优化）产出逻辑计划 → 执行引擎 → 调本模块的 get_page/new_page/unpin/flush；数据库模块（目录/堆表/索引/事务）直接消费本模块接口。
- OS 课程映射：分页与地址映射、置换算法、文件系统 I/O、读者-写者、死锁、内存回收、崩溃恢复、进程调度（后台线程）。

### 段 2：存储 / 缓存 / 持久化（7 min）
1. 页式存储：4KB 页、page_id、分配/释放/读回；空闲页 `.fpl` 位图（跨重启复用 + 防活页误复用 + 页数漂移安全丢弃）。
2. 替换策略族：LRU / FIFO / CLOCK / LRU-K（策略模式可插拔；K=1 退化为 LRU；命中率对照）。
3. 缓冲池：内存上限可配置、命中统计、替换日志、页级读写闩（防写盘撕裂）、后台刷脏。
4. 持久化：`.crc` 页校验、真持久 fsync（`_commit`/`fsync`）、WAL-before-data。
5. 温度感知刷盘：热页留池、冷页写回（自适应阈值）。

### 段 3：并发 / 恢复（8 min）
1. 锁管理：16 分片 + splitmix64（行锁与表锁同片）、层级冲突、锁序不变量（shard → meta；latch → log → io）。
2. 死锁：等待图 DFS + victim 中止 + 超时兜底。
3. 隔离级别四档：RC 语句末释放读锁 / RR 提交释放 / SERIALIZABLE 谓词锁防幻读 / SNAPSHOT 免读锁 + FCW。
4. MVCC：版本链 + 内存版本索引（O(1) 查询）+ 快照低水位（O(1)，≈465×）+ 内联真空。
5. 谓词锁区间树：O(log P + K) 冲突查询。
6. WAL 组提交：leader-follower 批量 fsync（9.8× 削减；窗口推荐 10ms）。
7. B+Tree 乐观页级并发：页级闩 + 版本校验乐观重启（16 线程 3.18×）；U1 再平衡 + 物理删页可靠回收。

### 段 4：查询优化协同（3 min）
- JOIN 顺序启发式、聚合下推（PreAggScan）、子查询去关联（SEMI/ANTI JOIN）——各自 EXPLAIN 实证 + 保守守底零回归。
- 强调：编译模块的优化结果驱动本模块更高效的扫描/连接执行，体现三模块协同。

## 4. 备选口径（QA 可能问到的对比结论）

| 问点 | 一句话回答 |
|---|---|
| 为什么用 .fpl 旁路文件？ | 零数据文件布局变更、旧库逐字节兼容；数据安全优先（漂移即丢弃） |
| LRU-K 为什么优于 LRU？ | 抗顺序扫描污染（historic 集），K=1 退化为 LRU，命中率 ≥ LRU |
| 乐观并发为何不阻塞？ | 读路径版本校验失败即整体重启（无等待环），与死锁检测正交 |
| 组提交窗口怎么定？ | 参数扫描取膝点：10ms 后 fsync 曲线走平（-17% 主体收益） |
| 子查询为何不全部去关联？ | NOT IN 的 NULL 语义与 ANTI 不等价，疑点保守守底零回归 |
