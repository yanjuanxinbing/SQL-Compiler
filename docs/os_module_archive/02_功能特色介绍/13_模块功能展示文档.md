## 1. 构建与启动

```powershell
# 1) 构建（CMake + MinGW GCC，C++17）
cmake -S . -B build
cmake --build build -j 8          # 产物：build\sqlcompiler.exe、build\storage_ut.exe

# 2) 启动数据库 CLI（进入 REPL，出现 sqlcompiler> 提示符）
.\build\sqlcompiler.exe demo.db
```

`demo.db` 首次启动自动建库；数据文件（页=4KB 块）、WAL、`.crc` 校验、`.fpl` 空闲页位图在首次使用时按需生成。

## 2. 页面管理功能操作流程

### 2.1 建表与数据写入（页式存储 + 缓冲池 + WAL 全程生效）

```sql
CREATE TABLE customers(id INT, name VARCHAR, city VARCHAR);
INSERT INTO customers VALUES (1,'Alice','BJ'),(2,'Bob','SH'),(3,'Charlie','BJ'),(4,'David','GZ'),(5,'Eve','SH');
SELECT * FROM customers ORDER BY id;
```

| 操作 | 模块动作 |
|---|---|
| CREATE TABLE | SystemCatalog 建表 → TableHeap 分配头页 → B+Tree 建索引 |
| INSERT | 逐行取缓冲池页（GetPage/UnpinPage）→ 页写闩内落版本 → 索引插入 → 页标记脏 → 提交组提交刷 WAL |
| SELECT | SeqScan 页级读闩 + MVCC 版本可见性过滤 |

### 2.2 替换策略演示（\stats 观察命中与替换）

```sql
SELECT id, amount FROM orders o JOIN customers c ON c.id = o.cust_id WHERE c.city='BJ';
\stats
```

`\stats` 输出（节选）：
```
buffer pool        : frames=64(256KB) used=16 ... hit=... miss=... repl=...
replacement policy : LRU-K(K=2)
page fault rate    : xx%
lock waits         : ...
subquery cache     : materialize=N hits=M
```

### 2.3 索引查询（索引路径选择）

```sql
CREATE INDEX idx_orders_cust ON orders(cust_id);
EXPLAIN SELECT * FROM orders WHERE cust_id = 3;   -- 应出现 IndexScan
```

### 2.4 事务与崩溃恢复演示

```sql
BEGIN;
UPDATE customers SET city='HZ' WHERE id=1;
ROLLBACK;
SELECT city FROM customers WHERE id=1;            -- 仍为 BJ
```

崩溃注入演示（两阶段脚本）：
```powershell
powershell -ExecutionPolicy Bypass -File tests\run_sql_regression.ps1   # 含 49/50 两阶段崩溃注入
```
- 49_acid_recovery：未提交 UPDATE 后 `\crash` → 重启后回滚；已提交变更持久。
- 50_undo_clr：ROLLBACK 中途 `\crash_after_undo_steps 1` → 重启后 CLR 链补做全部撤销。

### 2.5 查询优化演示（Phase 6 U3）

```sql
EXPLAIN SELECT name FROM customers c WHERE EXISTS (SELECT 1 FROM orders o WHERE o.cust_id = c.id);
-- 应输出 Join(SEMI, (o.cust_id = c.id)) —— 相关子查询去关联为半连接

EXPLAIN SELECT city, COUNT(*), SUM(id) FROM customers GROUP BY city;
-- 应输出 PreAggScan —— 聚合下推至扫描层

SELECT name, (SELECT count(*) FROM orders) AS cnt FROM customers ORDER BY id;
-- 非相关子查询物化缓存：\stats 中 subquery cache materialize=1 hits=4
```

### 2.6 可观测性与诊断

```sql
\stats       -- 命中率/替换日志/IO/内存/锁等待/索引/子查询缓存全指标
\analyze     -- 页面/索引使用分析
\bench 8 300 -- 8 会话并发压力（全 ok=2400 err=0）
```

## 3. 关键环境变量（演示用）

| 变量 | 作用 | 演示值 |
|---|---|---|
| `SQLCOMPILER_BUFFER_MEMORY` | 缓冲池内存上限（字节） | `8192`（2 帧）对比默认 64 帧 |
| `SQLCOMPILER_BG_FLUSH_MS` | 后台刷脏间隔（0=关） | `50` |
| `SQLCOMPILER_GROUPCOMMIT_WINDOW_MS` | 组提交窗口 | `10`（推荐，fsync -17%） |
| `SQLCOMPILER_TEMP_FLUSH` | 温度感知刷盘开关 | 设置即启用 |
| `SQLCOMPILER_HOT_RATIO_PERCENT` | 热页占比目标 | `20` |
