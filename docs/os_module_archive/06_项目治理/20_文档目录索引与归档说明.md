## 4. 统一格式规范

### 4.1 标题层级

| 级别 | 用法 | 示例 |
|---|---|---|
| H1 | 文档标题（每个文件唯一） | `# 操作系统页面管理模块 · 设计文档` |
| H2 | 一级章节 | `## 1. 模块定位与总体架构` |
| H3 | 二级章节 | `### 2.1 缓存管理（第 2~3 层）` |
| H4 | 段落标题 | `#### 4.1 行锁` |
| H5+ | 不使用 | — |

### 4.2 术语统一

| 标准术语 | 禁用品 |
|---|---|
| 页式存储 | 分页存储 / 页面存储 |
| 缓冲池 / BPM | 缓存池 / BufferPool |
| 替换策略 | 淘汰策略 |
| 写闩 / 读闩 | 写锁 / 读锁（与表锁/行锁区分） |
| 谓词锁 | 区间锁 |
| 锁分片 | 锁分桶 / 锁切片 |
| 组提交 | group commit（首次出现中英并存） |
| 快照隔离 / SNAPSHOT | SI（缩写首次出现需拼全） |
| 一致性证明 | 安全性论证 |
| 物理删页 | 实际删页 |
| 区间树 | 间隔树 |

### 4.3 图表样式

- 表格：左对齐 + 列对齐数字右对齐；表头必填
- 代码块：标注语言（`cpp` / `sql` / `text` / `cmake` / `powershell`）
- 树状图：用 ```text``` 代码块 + 字符树
- 文件引用：用 `[文件名](file:///路径)` 协议
- 时间戳：统一 ISO 8601（`2026-09-14 22:54:46`）或日期（`2026-09-14`）

### 4.4 文档版本标记

每篇文档顶部必含：
```markdown
- 项目：SQL-Compiler 小型数据库系统
- 模块：操作系统页面管理（页式存储 / 缓存管理 / 替换策略 / 持久化 / 事务并发与崩溃恢复）
- 编制日期：YYYY-MM-DD（初版 / 更新版）
- 编制依据：Manual.md（指导书）三.2 + 三.3
- 状态：测试全绿/部分已知 flaky/待修复
```

### 4.5 数据声明规范

- 实测基线必须包含：`storage_ut NNN checks / N fails`、`SQL 回归 N / N`、`-Wall -Wextra 告警 N`
- 性能数字必须含：基线、当前值、加速比、测试条件
- 已知 flaky 必须显式标注：测试名 + flaky 原因 + 重跑结果
