## 3. 模块一句话概览

- **页式存储**：固定 4KB 页、唯一页号、`read_page`/`write_page`/分配/释放接口；块设备抽象（File/Memory/Sparse/Network/FaultInjecting）；
- **缓存管理**：缓冲池（pin 计数 + 脏标记 + 命中统计 + 替换日志），LRU / FIFO / CLOCK / LRU-K 可插拔替换；温度感知刷脏 + 自适应阈值、后台刷脏、内存上限可配；
- **持久化**：WAL-before-data、真持久 fsync、组提交（时间窗可配）、页 CRC（`.crc`）、空闲页位图（`.fpl`）、崩溃恢复（redo/undo + CLR 链）；
- **并发与事务**：页级读写闩、行锁/表锁/谓词锁（区间树）、分片锁（16 shard）、死锁检测、隔离级别（RC/SERIALIZABLE/SNAPSHOT）、MVCC 版本链、FCW、乐观 B+Tree 页级并发；
- **优化**：快照低水位 O(1)、内联真空、版本链 O(1) 查询、索引墓碑回收、谓词区间树、温度感知刷盘、LRU-K；
- **可观测**：`\stats` 命中构成/脏页年龄/刷脏直方图/IO 队列、`\analyze` 页映射/CRC 计数、`\bench` 进程内多会话并发混合负载基准（吞吐/avg/p95 延迟/命中率，U2-1）。

## 4. 测试结论（简要）

- 存储单元测试：**292643 checks / 0 fails**（U3-3 后，一键复现 `run_repro_all.ps1` ALL GREEN）；
- SQL 端到端回归：**56 passed / 0 failed**（含 49/50 崩溃注入两阶段）；
- `-Wall -Wextra` 审计：**0 warning / 0 error**（清理 234 条告警，行为零变化）；
- 性能基准：快照水位读取约 **465×** 加速，WAL 组提交 fsync **9.8×~10.7×** 减少，B+Tree 并发写 **3.18×**（16 线程），分片锁异表 **5.8×**；
- 集成冒烟：CLI 全链路（DDL/DML/索引/事务/`\stats`/`\analyze`）exit=0 无错误。
