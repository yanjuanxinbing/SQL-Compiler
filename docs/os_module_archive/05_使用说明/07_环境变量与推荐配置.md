# 环境变量矩阵与推荐配置

- 项目：SQL-Compiler 小型数据库系统
- 适用：Phase 5（OS 页面管理模块）周期 4 调参实验固化
- 更新日期：2026-09-14

> 全部环境变量均为**可选调优开关**：不设置时行为与旧版逐字节一致（默认保守、
> 完全兼容），设置后仅改变缓存/刷盘/日志聚合/真空的调度策略，不改变任何执行语义
> 与磁盘格式。G7「默认行为保守」由此闭环：默认关闭属有意的保守设计，演示/压测时
> 按下表开启即可。

## 1. 环境变量总览

| 环境变量 | 默认 | 语义 | 读取位置 |
|---|---|---|---|
| `SQLCOMPILER_BUFFER_MEMORY` | 未设置（64 帧 = 256 KB） | 缓冲池内存上限（字节），内部换算为帧数（不足一页按一页） | `src/main.cpp` |
| `SQLCOMPILER_TEMP_FLUSH` | 未设置（关闭） | 温度感知刷盘：全量刷脏只写回冷脏页，热脏页延后留池（NO-FORCE + WAL 保证正确性）；开启即同时启用自适应热阈值（P 分位动态估计） | `src/db/Database.cpp` |
| `SQLCOMPILER_HOT_RATIO_PERCENT` | 20（%） | 自适应热阈值的目标热页占比（1..99）；须与 `SQLCOMPILER_TEMP_FLUSH` 配合 | `src/db/Database.cpp` |
| `SQLCOMPILER_BG_FLUSH_MS` | 0（关闭） | 后台异步刷脏线程间隔（毫秒），>0 开启 | `src/main.cpp` |
| `SQLCOMPILER_BG_VACUUM_MS` | 0（关闭） | 后台 MVCC 多版本真空线程间隔（毫秒），>0 开启 | `src/main.cpp` |
| `SQLCOMPILER_GROUPCOMMIT_WINDOW_MS` | 0（纯跟随者聚合） | 组提交时间窗（毫秒）：窗口内提交合并为一批 fsync | `src/txn/LogManager.cpp` |

## 2. 观测面（`\stats` 输出）

| 字段 | 含义 |
|---|---|
| `buffer pool frames / buffer memory` | 帧数与内存占用（used/cap、帧数） |
| `hits / misses / repl` | 缓冲池命中/缺失/替换计数 |
| `dirty writebacks (cold=…, hot=…)` | 冷/热脏页写回计数（温度感知刷盘的分流观测） |
| `temp flush` | 温度刷盘开关、热阈值、自适应状态（ratio/last_est/sampled） |
| `hit ratio` | 命中率（%） |
| `disk pages / free` | 磁盘页数与空闲页数（.fpl 位图） |
| `disk reads / writes` | 磁盘 I/O 计数 |
| `wal fsyncs` | 累计真实 fsync 次数（组提交摊薄观测） |
| `background flush` | 后台刷脏间隔与 ticks |

## 3. 推荐配置

参数扫描实验（`tests\run_param_sweep.ps1`，结果见 `docs\test_evidence\param_sweep.log`）
的观测结论：

| 配置 | 推荐值 | 理由 |
|---|---|---|
| `SQLCOMPILER_BUFFER_MEMORY` | `1048576`（1 MB / 256 帧） | 64 帧已覆盖 3k 行测试数据集（命中率 99.99%）；16 帧时命中率降至 99.05% 且 fsync 从 219 飙到 857（换页触发的 WAL 同步）。1 MB 为更大工作集留余量 |
| `SQLCOMPILER_TEMP_FLUSH` | `1` | 写回从「全量」分流为 cold/hot（实测 346 → cold 14 + hot 332），热页留池延后写回 |
| `SQLCOMPILER_HOT_RATIO_PERCENT` | `20`（默认） | 自适应目标热页占比，随工作集温度自动收敛 |
| `SQLCOMPILER_BG_FLUSH_MS` | `10` | 后台异步刷脏把写回摊到后台线程（实测 ticks=297）；短负载总 I/O 略增（12345→13070），长运行下提交路径 I/O 削减 |
| `SQLCOMPILER_GROUPCOMMIT_WINDOW_MS` | `2`（**仅多会话高频提交**） | 单会话串行提交下窗口徒增等待（12 提交 + 逐页 flush × 窗口 → 2.6s→3.6s），fsync 不摊薄；多会话并发下才合并（UT `TestGroupCommitTimeWindow` 实测 fsync 6.5× 摊薄） |
| `SQLCOMPILER_BG_VACUUM_MS` | `5` | 长事务持续更新场景回收旧版本槽位；短负载无副作用 |

典型演示启动（PowerShell）：

```powershell
$env:SQLCOMPILER_BUFFER_MEMORY = "1048576"
$env:SQLCOMPILER_TEMP_FLUSH = "1"
$env:SQLCOMPILER_BG_FLUSH_MS = "10"
$env:SQLCOMPILER_GROUPCOMMIT_WINDOW_MS = "2"
$env:SQLCOMPILER_BG_VACUUM_MS = "5"
.\build\sqlcompiler.exe demo.db
```
