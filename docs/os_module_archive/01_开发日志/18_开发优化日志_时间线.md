## 3. 关键问题修复与优化记录（按时间排序）

### 3.1 T1-T3 阶段（早期修复，奠基性）

| 日期 | 问题 | 根因 | 修复 | 影响范围 |
|---|---|---|---|---|
| T1 | 错误路径帧/页号泄漏 | `GetPage/NewPage` 失败未回滚 `free_list_`/`DeallocatePage` | 异常路径补回滚 | BufferPoolManager |
| T1 | CLI stdin 丢首批命令 | PowerShell `System.Diagnostics.Process` 默认非行缓冲 | 启用行缓冲模式 | CLI 入口 |
| T2 | 多会话链表分叉丢行 | D7 缓冲池全局 latch_ 只串行化单次帧访问，不能串行化 check-then-act 序列 | 引入 per-table `write_mutex_`（递归），同帧二次拿独占页锁先 `PageWriteGuard::Release()` 再嵌套 | TableHeap::InsertTuple 写序列 |
| T2 | 死锁检测失效 | `TryLock` 探针未保留等待登记边，DFS 无法识别后续成环事务 | 探针返回前补登记边，victim 撤销自己边 | LockManager |
| T2 | RC 行锁泄漏 | Session `ExecuteSubplan` 绕过 `Execute()` 的 read lock release | 补 success/exception 路径释放 | Session 路径 |
| T2 | FCW 丢失更新 | `SetActiveTransaction` 在加 X 锁后调用，snapshot base 错 | 挂载事务移到读行循环前 | Transaction API |
| T2 | UPSERT/FCW 失效 | 写算子（Delete/Update/Upsert::UpdateConflictingRow）未调 `SetSnapshot`，`GetTuple` 退化为物理头读，多版本槽被当独立行 | 写算子 read loop 前补 `SetSnapshot` | Delete/Update/Upsert |
| T3 | B+Tree 写入丢叶页 | `LatchedPageGuard` 创建时 `LatchPinned` 丢弃 dirty flag 且不处理 Unpin | dirty 标记在 `PageGuard` 上 + pin 所有权（left_pin/right_pin/parent_pin） | B+Tree 写路径 |
| T3 | B+Tree 写锁自锁 | 同帧二次拿写闩未先 Release | `PageWriteGuard::Release()` 后再嵌套 | B+Tree update/delete 路径 |
| T3 | 快照水位 O(n) 扫描 | 每快照扫描全活跃事务列表 | 维护 `SnapshotTracker` 活跃列表+ 低水位 O(1) | 快照构建 |
| T3 | 版本链 O(n) 查询 | 每查询线性扫描版本链 | 5 元 head slot + 内存缓存索引 | GetTuple O(1) |
| T3 | 谓词锁全树重建 | 全 O(P log P) 重建 | 增量 O(D log P) + 脏标记延迟重建 | PredicateIntervalTree |
| T3 | .fpl 加载数据安全优先 | bitmap 与 next_page_id_ 不一致 | 校验 magic/version+pages 一致才采纳 | DiskManager 启动 |

### 3.2 Phase 5 阶段（中期优化）

| 日期 | 问题 | 根因 | 修复 | 影响范围 |
|---|---|---|---|---|
| Phase5 | 行锁扩展至大表性能下降 | 固定升级阈值不区分大小表 | 动态阈值 = 行锁数 × 表大小 + 冲突采样 | LockManager |
| Phase5 | 自适应阈值退化 | P 百分位 + flat-distribution guard + boundary-tier cap | `EstimateAdaptiveThreshold`（默认 20% 目标占比） | Temperature |
| Phase5 | LRU-K 退化 | K=1 时变 LRU | 边界保证 LRU-K 地板为 K | Replacer |
| Phase5 | 表锁/行锁分片冲突 | 全局 mutex 串行化 | 16 shard（splitmix64 哈希） + `table_hint≥0` 跳 meta_mutex | LockManager 热点 |
| Phase5 | 行锁升级偏向 | 升级点固定 | 升级阈值动态 + 升级状态在 meta_mutex 下 | LockManager |
| Phase5 | 锁等待不可观测 | 无分布统计 | `GetLockWaitStats` + 原子计数（仅阻塞路径自增、授权热路径零开销） | `\stats` 扩展 |
| Phase5 | CRC 介质监测缺失 | 默认未启用 | `.crc` 旁路 + headerless 4-byte u32 CRC32（IEEE 0xEDB88320）；损坏计入 `\analyze` | DiskManager |
| Phase5 | 大文件 >2GB 定位失败 | 32 位 fseek/ftell | 64 位 `_fseeki64`/`_ftelli64`（Windows）、`fseeko`/`ftello`（POSIX） | DiskManager |
| Phase5 | CRC 初始化数据竞争 | 惰性 init 线程不安全 | `inline constexpr std::array<uint32_t,256>` const-expr 表 | OsModuleOptimizations |
| Phase5 | LRU Unpin 性能 | find + operator[] 两次哈希 | `position_map_.emplace(id, --list.end())` 单哈希 | LRUKReplacer |
| Phase5 | .crc 写入顺序 | 损坏数据先于 crc | Sync() 强制先 `.crc` 后 data | DiskManager |
| Phase5 | 锁等待超时 | 永久阻塞 | kIsolationLockWaitMs = 5000 | LockManager |
