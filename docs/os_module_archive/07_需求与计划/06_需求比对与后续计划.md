#### 周期 3 完成记录（实现要点）

1. **温度阈值自适应**（`include/storage/BufferPoolManager.h` + `src/storage/BufferPoolManager.cpp`）
   - `EstimateAdaptiveThreshold`：样本 = 当前全部脏页访问计数（升序），P 分位估计——
     目标热页数 `goal = round(hot_ratio_percent_% × n)`（默认 20%，可配），阈值取高频端
     第 goal 个访问数，热页占比随工作集温度自动收敛；
   - **边界同温层保护**：热页数被放大到 `cap = max(goal, n-goal)` 之上时抬升阈值整层判冷，
     避免低频大量同温页全部判热（占比偏置、收敛失效）；
   - **平坦分布保护**：脏页计数极差 < 2（整数计数下的同温）时阈值上推全体判冷，防止
     「全部判热 → 刷盘空转、脏页长期滞留」；
   - **LRU-K 联动**：替换策略为 LRU-K 时阈值至少取 K——访问 < K 的页是 LRU-K 语义下的
     非相关一次性引用，恒按冷页写回，热页判定与淘汰策略对齐；
   - 显式 `SetHotAccessThreshold` 手动设值关闭自适应（手动优先级最高）；`\stats` 观测
     `last_estimated_threshold_` / `last_dirty_sampled_`。
2. **LockManager 分片锁**（`include/storage/LockManager.h` + `src/storage/LockManager.cpp`）
   - 锁表与谓词表按所属表/命名空间分片（`kLockShardCount = 16`），每分片独立互斥 + 条件变量 +
     锁表 + 谓词表；分片路由 `TableShard/ShardOf`（splitmix64 哈希）：
     表资源（res ≥ 0）按自身哈希；行资源（res < 0）按 `table_hint`（生产路径恒传）→ 已登记
     归属（`RegisterRowGroup`）→ 自身哈希；
   - **行锁与所属表锁同片不变量**：多粒度层级冲突（`HierarchyConflicts`）、锁升级、行锁计数
     全部在单分片内完成，不跨分片持锁；跨分片等待图与归属登记由全局 `meta_mutex_` 保护，
     锁序恒为「分片互斥 → meta_mutex_」；
   - **行锁热路径免全局锁**：`table_hint ≥ 0` 时层级冲突直接以提示作为所属表，免读
     `meta_mutex_`，分片收益不被全局互斥稀释；
   - 执行链路适配：`SeqScanExecutor`/`IndexScanExecutor` 行读锁、`AcquireRowReadLock`/
     `AcquireRowWriteLock`、语句末行读锁释放全部传入表堆首页页号作 `table_hint`（与获取时同片）。
3. **压力测试**（`tests/storage/storage_ut.cpp`，`TestLockManagerShardThroughput`）
   - 16 线程 × 20000 次「行 X 锁 + 释放」；同表（全部线程共享一张表 → 单分片串行化）vs
     异表（每线程独立表 → 行锁散布多分片并行）；断言异表吞吐严格高于同表。
- **测试证据**：storage_ut **58871 checks / 0 fails**（PASS）；分片锁基准
  同表 **370370 ops/s** vs 异表 **2133333 ops/s（5.8× 加速）**；SQL 回归 **55 passed / 0 failed**
  （含 49/50 崩溃注入两阶段）。
