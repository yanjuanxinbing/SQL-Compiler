## 里程碑依赖与风险

- **U1 → U2**：树高/利用率控制需 U1 完成后才能给出稳定基线曲线；U3/U4 与 U1、U2 可并行（不同模块层）；
- **U5 依赖 U1–U4**（收口）；
- **主要风险**：B+Tree 合并的并发正确性（多写闩 + 版本复核）复杂度高——沿用「先 pin 后加闩」与双层守卫既有范式，先小规模并发测试再全量；若实现难度超预期，可将「再分配（redistribute）」作为第一阶段、「合并（merge）」作为第二阶段分步交付；
- **次要风险**：JOIN 重排序估计基数依赖统计信息——初版用启发式（表规模×谓词选择性粗估），不引入直方图。
